# Demo video script prompt — Focus Ghost

Use this prompt when drafting the < 3 minute demo video script for the Devpost
submission. The video will be rendered with Remotion and published on public YouTube.

## Prompt

> Write a demo video script (under 3 minutes, ~380 words spoken) for Focus Ghost,
> a haunted Pomodoro focus app built for Kiroween 2026.
>
> Structure (with on-screen action for each beat):
> 1. **Hook (0:00–0:15):** "Your focus has a soul." Show the ghost, dim and hungry.
> 2. **Problem (0:15–0:35):** focus apps are boring; streaks feel like chores. Show a
>    plain timer vs. our ghost.
> 3. **The idea (0:35–1:05):** Pomodoro feeds the ghost; distractions weaken it. Show
>    a focus session completing → ghost eats, gains XP, glows.
> 4. **The product tour (1:05–2:15):** timer → ghost evolution stages → streak &
>    Graveyard heatmap → stats → settings (rename your ghost).
> 5. **How it was built (2:15–2:40):** spec-driven with Kiro — show the `.kiro/`
>    specs, steering, hooks, and the custom ghost-writer agent.
> 6. **Close (2:40–2:55):** "Feed it, or it fades." Show the live app URL + GitHub
>    repo. End card: Focus Ghost — Kiroween 2026.
>
> Rules: spoken English, plain words, no jargon. Every claim must be visible on
> screen at that moment. No third-party trademarks or copyrighted music. Keep the
> total under 3 minutes — the judges are not required to watch beyond that.

## After drafting

- Read the script aloud and time it. Cut until it fits 2:45.
- List the exact screen recordings needed per beat (Remotion scenes).
- Note any line that needs a UI state not yet built — flag it as a build gap in
  PLAN.md, don't fake it in the video.
